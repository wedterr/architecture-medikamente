# Задание 6. Классификация данных

- Слой интеграции данных (Integration Layer): отвечает за сбор, предобработку, очистку, нормализацию и стандартизацию данных из разных источников (Excel, 1С, другие). Обеспечивает обработку изменений структуры данных и удаление дубликатов.

- Слой хранения данных (Storage Layer или Data Lake): централизованное хранилище для данных всех уровней, включая сырые и обработанные данные. Позволяет структурировать данные с учётом бизнес-доменов и поддерживать масштабируемость для BI, ML и AI.

- Слой аналитики (Analytics Layer): предоставляет инструменты для построения аналитических моделей, визуализаций, отчетов и ML/AI обучения. Работает с подготовленными данными, обеспечивая ускоренный и удобный доступ для пользователей.

- Слой безопасности и управления доступом (Security & Access Layer): реализует политики контроля доступа с использованием RBAC и ABAC, обеспечивает классификацию данных по уровню конфиденциальности, шифрование и аудит всех действий с данными для предотвращения несанкционированного доступа.

- Слой классификации и тегирования данных: движок, который перед загрузкой данных в аналитическое хранилище автоматически определяет уровень конфиденциальности и присваивает необходимые метки, учитывая изменяющиеся структуры данных и отсутствие разметки.

- Слой мониторинга и аудита (Monitoring & Auditing Layer): отслеживает качество данных, эффективность аналитики, аномалии доступа и действия пользователей, отправляет оповещения при нарушениях безопасности.
