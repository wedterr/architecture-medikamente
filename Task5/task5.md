# Задание 5. Разработка cutover-плана

### Выбор варианта миграции

High-level design важен как основа проектирования, и его следует применять как часть подготовки, но использование только этого варианта не решит быстро текущих задач миграции.

Parallel run подойдет для особо чувствительных сервисов, но дорого и сложно для компании с ограниченными ресурсами и множеством ручных процессов.

С учётом текущего состояния: монолитная система, ручная работа с конфиденциальными данными, отсутствие аудита и необходимости построения безопасных, масштабируемых и легко сопровождаемых сервисов, наиболее сбалансированным решением будет Branch by abstraction. Branch by abstraction сочетает постепенность, контроль и техническую устойчивость.
